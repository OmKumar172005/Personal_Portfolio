# Om Kumar — Personal Portfolio Landing Page

A responsive one-page developer portfolio built with semantic HTML5 and CSS. It includes an introduction, five skills, two project summaries, social/contact links, responsive layouts, hover states, smooth scrolling, and visible keyboard focus styles.

## Files
- `index.html` — semantic page structure and content
- `style.css` — colors, typography, Flexbox/Grid layouts, and responsive media queries
- `images/` — folder reserved for optional personal/project images (the current design uses CSS illustrations)

## Run locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and select **Open with Live Server**.
4. Test the page at 360px, 768px, and 1280px using browser developer tools.

## Personalize before publishing
1. Replace `your.email@example.com` in `index.html` with your real email address.
2. Replace the generic GitHub and LinkedIn URLs with your own profile URLs.
3. Review the bio, skills, and project descriptions to ensure they accurately describe your own experience.
4. Add project repository links if available.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `personal-portfolio`).
2. Upload `index.html`, `style.css`, and the `images` folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under the build/deployment settings, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the deployment and open the public URL shown on the Pages settings screen.

## Design decision
The design uses navy, blue, and mint as a three-color palette. CSS-built illustrations avoid heavy image files and keep the page quick to load, while Grid and media queries let cards adapt to different screen sizes.
